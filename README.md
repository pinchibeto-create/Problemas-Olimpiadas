# Banco de problemas matemáticos · Fase 6

Buscador estático de problemas de secundaria por grado, contenido y PDA de la NEM. Fuente: `Problemas_Contenidos_y_PDA_Fase6_NEM_Actualizado-v7.docx` (versión suministrada). Contiene 1,433 reactivos, 14 contenidos, 72 PDA y 1,472 asociaciones sugeridas. Las asociaciones no son oficiales ni están validadas individualmente; las figuras ausentes y la falta de soluciones deben tenerse en cuenta. No se concede licencia de redistribución de las fuentes originales; verifica los permisos antes de hacer público el banco.

## Proyecto
Repositorio de datos y buscador de matemáticas. La clasificación original por contenido y las relaciones sugeridas por PDA se conservan separadas. La publicación del banco requiere comprobar los permisos de redistribución de los reactivos originales.

La configuración de Netlify y los archivos de datos se incorporan en los siguientes commits.
